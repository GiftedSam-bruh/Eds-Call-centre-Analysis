# Call Centre Performance Analysis

A data analytics project examining customer service performance
using call-centre operational data.

## Objective

The objective was to identify performance issues and opportunities
to improve customer service outcomes.

## Tools

- Python
- Excel
- Data visualisation
- Business analytics

## Analysis

The project investigated:

- missed calls
- call resolution
- customer satisfaction
- agent performance
- department performance

## Key Findings

- Approximately 20% of calls were missed.
- Customer satisfaction was materially affected by unresolved calls.
- Performance differed between agents and departments.
